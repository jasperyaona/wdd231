# Philippine Travel Explorer

A WDD 231 individual project starter by Jasper James Yaona.

## Run locally
Because the pages load `data/destinations.json` with `fetch()`, do not open `index.html` directly using `file://`. Open this folder in VS Code and run it with Live Server, or use another local HTTP server.

## Image filenames and recommended dimensions
Find appropriately licensed images and save them in the `images/` folder using the exact filenames referenced in the HTML and JSON.

| Filename | Used for | Recommended dimensions |
|---|---|---|
| `philippines-hero.jpg` | Home hero | 1600 × 700 px |
| `destinations-banner.jpg` | Destinations page banner | 1600 × 500 px |
| `trip-planning-banner.jpg` | Plan page banner | 1600 × 500 px |
| `palawan-el-nido.jpg` | Destination card | 600 × 400 px |
| `bohol-chocolate-hills.jpg` | Destination card | 600 × 400 px |
| Other destination filenames | Destination cards/details | 600 × 400 px |
| `philippines-travel-social.jpg` | Open Graph/social preview | 1200 × 630 px |
| `favicon.ico` | Browser tab icon | 32 × 32 px or multi-size ICO |

The CSS crops card images to a 3:2 shape and the hero/banner images to wider shapes. If possible, compress photos to WebP or optimized JPEG and keep each image under about 125 kB where practical. If you change an image extension, also update the filename in the HTML or JSON.
